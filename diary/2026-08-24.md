## Bugs / Errors Discovered
### Bug #02
- **Symptoms**: `aiosqlite` thread startup error (`RuntimeError: threads can only be started once`) during test fixture execution.
- **Root Cause**: Double-awaiting `aiosqlite.connect` via `async with await self._get_connection()`.
- **Fix**: Refactored `connect()` into an async context manager managing connection lifecycle and shared connection reuse for `:memory:`.
- **Commit / PR**: local fix
