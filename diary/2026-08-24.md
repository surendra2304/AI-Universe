## Bugs / Errors Discovered
### Bug #01
- **Symptoms**: `setuptools` build error during `pip install -e .` reporting `Multiple top-level packages discovered in a flat-layout: ['app', 'data', 'diary']`.
- **Root Cause**: Flat layout without explicit package find directives caused non-code folders (`data`, `diary`) to be treated as candidate packages.
- **Fix**: Added `[tool.setuptools.packages.find]` with `where = ["."]` and `include = ["app*"]` in `pyproject.toml`.
- **Commit / PR**: `5847287`
- **Verification**: `pip install -e ".[dev]"` succeeded cleanly.
