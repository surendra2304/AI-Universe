### Core Advisory Architecture & Safety Rule

The most critical design constraint of this subsystem is its strict safety invariant:
- **AI Universe is strictly advisory**: It NEVER calls exchange APIs, NEVER signs transactions or private keys, and NEVER executes trades directly.
- Autonomous trading bots send performance telemetry (equity, win rate, profit factor, drawdown, consecutive loss streaks, per-strategy metrics, regime data, and recent closed trades) on a schedule or upon drawdown events.
- AI Universe runs a structured multi-agent consultation and returns bounded parameter recommendations. The trading bot independently validates these recommendations against its own deterministic hard bounds before applying them.

### Key Components & Validation Tools Built

1. **Synthetic Telemetry Generator (`scripts/generate_synthetic_telemetry.py`)**:
   - Generates four representative test fixtures under `tests/fixtures/`:
     - `telemetry_healthy.json`: High win rate (68%), profit factor 1.85, low drawdown (2.1%).
     - `telemetry_struggling.json`: Low win rate (35%), profit factor 0.72, drawdown 9.8%, 6 consecutive losses.
     - `telemetry_insufficient_data.json`: Low trade sample count ($N=12 < 20$).
     - `telemetry_mixed_strategies.json`: Portfolio of 3 distinct strategies with varying performance.

2. **Recommendation Quality Audit Tool (`scripts/audit_consultation_quality.py`)**:
   - Evaluates response coherence (e.g. no widening of stop loss during equity drops).
   - Validates quantitative metric citations in rationale strings.
   - Enforces single-step parameter adjustment bounds ($\le \pm 50\%$) and verifies absence of forbidden parameters (`leverage`, `margin_mode`).
   - Achieved **100/100 Quality Score** across all audited scenarios.

3. **Load & Stress Testing (`tests/test_consult_load.py`)**:
   - Dispatched 100 concurrent consultation requests across unique `bot_id` instances.
   - Measured latency percentiles: Average = 40.37s, P50 = 40.58s, P95 = 41.63s ($< 180$s SLA limit), Max = 41.71s.
   - Verified 100% success rate with zero false-positive 429 rate limit triggers.

4. **FastAPI Endpoints & Multi-Agent Debate Engine**:
   - `POST /v1/trading/consult`: 180s server timeout fallback to safe `NO_CHANGE`.
   - `GET /v1/trading/consult/health`: Operational health check.
   - `GET /v1/trading/decisions/{decision_id}`: Persistent SQLite memory lookup.
   - Zero-credential recursive scanner instantly rejecting `api_key`/`secret` fields with HTTP 400.
