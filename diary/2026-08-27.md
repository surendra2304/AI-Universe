### Core Advisory Architecture & Safety Rule

The most critical design constraint of this subsystem is its strict safety invariant:
- **AI Universe is strictly advisory**: It NEVER calls exchange APIs, NEVER signs transactions or private keys, and NEVER executes trades directly.
- Autonomous trading bots send performance telemetry (equity, win rate, profit factor, drawdown, consecutive loss streaks, per-strategy metrics, regime data, and recent closed trades) on a schedule or upon drawdown events.
- AI Universe runs a structured multi-agent consultation and returns bounded parameter recommendations. The trading bot independently validates these recommendations against its own deterministic hard bounds before applying them.

---

### Key Components Built

1. **Pydantic Data Contracts (`app/schemas/trading_consult.py`)**:
   - `TradingConsultRequest`: Validates incoming bot telemetry, per-strategy breakdowns, active parameters, regime context, and recent trades. Restricts operational mode strictly to `PAPER` and `TESTNET`.
   - `AIUniverseDecision`: Emits structured decisions including `status` (`RECOMMENDATION`, `NO_CHANGE`, or `INSUFFICIENT_DATA`), confidence, bounded `parameter_changes`, narrative `risk_assessment`, `regime_analysis`, `dissent_notes`, and `debate_summary` with a 24-hour expiration (`valid_until`).

2. **Dedicated Multi-Agent Consultation Orchestrator (`app/services/trading_consult_service.py`)**:
   - Assembles a specialized debate panel: **Trading Analyst (`trading_analyst`)** (lead) $\rightarrow$ **Strategist** $\rightarrow$ **Adversarial Critic** $\rightarrow$ **Data Analyst** $\rightarrow$ **Synthesizer**.
   - Enforces hard synthesis constraints:
     - **Maximum 2 parameter changes** per decision (preferring 1).
     - Mandatory quantitative evidence from telemetry attached to every parameter change.
     - **$N < 20$ Trades Gate**: If sample size is below 20 closed trades, returns `status = "INSUFFICIENT_DATA"`.
     - **Healthy Gate**: If win rate, profit factor, and drawdown are healthy, returns `status = "NO_CHANGE"`.
   - Persists all consultation deliberation trails and scoped memories under the `trading_advisory` agent namespace in SQLite memory.

3. **FastAPI Endpoints & Security Boundaries (`app/routers/trading.py`)**:
   - `POST /v1/trading/consult`: Submits telemetry for consultation with a 180s server-side timeout fallback to safe `NO_CHANGE`.
   - `GET /v1/trading/consult/health`: Returns system health and available specialist agents.
   - `GET /v1/trading/decisions/{decision_id}`: Retrieves past decisions from persistent SQLite storage.
   - **Abuse Prevention & Security**: Enforces sliding-window rate limiting (max 20 requests per `bot_id` per hour), 1MB payload size limit, and recursive scanning that instantly rejects payloads containing exchange credentials (`api_key`, `secret`, `credential`, etc.) with HTTP 400.
